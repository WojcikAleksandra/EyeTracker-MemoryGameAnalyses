# MemoryGame_App – Project Overview

This folder contains a PyQt5 Memory Game application with optional eye-tracking (calibration + gaze logging) and basic post-game tools (gaze accuracy report, heatmap viewer).

---

## Quick start

### Run the game
From inside `MemoryGame_App/`:

python MemoryGame.py

### Run the game in dev mode 
(runs app with visible eye detection window)

python MemoryGame.py --dev

---

## Folder structure

### MemoryGame.py
Main entry point of the application (launches the GUI).

### pages/
UI pages / windows used by the app:
- calibration_screen.py – calibration page (user clicks calibration points)
- heatmap_view.py – heatmap visualization window

### images/
Card images used by the game:
- 1.png, 2.png, … – front faces
- backOfCard.png – card back image

### gaze_data/
CSV logs generated during gameplay when eye-tracking is enabled.
- New gaze logs are written here (or referenced from here)
- archived/ contains older gaze logs moved automatically (older: from previous app runs) 

Tip: If you don’t see gaze data after playing, you probably skipped calibration or played with gaze tracking disabled.

### game_history_data/
Saved gameplay history and click logs:
- game_history.json – list of past game results (used for leaderboard)
- click_log.csv – click data saved during the game (legacy click logger)

### gaze accuracy reports/
Text reports generated by gaze_accuracy_analysis.py, for example:
- gaze_accuracy_report_YYYYMMDD_HHMMSS_game1.txt

### Other .py files used by the app:
- app_data_paths.py - Utility module for managing application data paths. Handles user data directories for installed applications.
- gaze_data_logger.py - Module for logging gaze data during gameplay. Captures and saves eye-tracking data to CSV files.

### Installer-related files
Installer scripts and configuration:
- Installer instructions/ – documentation for installer usage
- build_installer.py, build_installer.bat, build_installer.sh – build scripts
- memory_game_installer.spec – PyInstaller spec file

### Environment / dependencies
- requirements.txt – Python dependencies (pip)
- environment.yml – Conda environment definition
- setup_conda_env.bat, setup_conda_env.sh – helper scripts for creating the conda env

---

## Eye tracking workflow (how it works)

1. Click Play in the app.
2. If calibration is not done yet, the app will ask you to calibrate.
3. After successful calibration, gaze tracking is enabled for the game.
4. Gaze samples and events are saved to a CSV file in gaze_data/.
5. The app stores the log path for later statistics and heatmap viewing.

You can reset calibration from:
Settings → Recalibrate Eye-Tracking

---

## Gaze accuracy analysis

### Run the analysis
From inside MemoryGame_App/:

python gaze_accuracy_analysis.py <id_of_game>

### What is <id_of_game>?
It’s the unique identifier in the gaze data filename created during the game, stored in gaze_data/ (or sometimes gaze_data/archived/).

Example (conceptually):
- gaze_data_20251222_182711_game1.csv → 20251222_182711_game1

### Output
The script generates a text report and saves it into:
gaze accuracy reports/

### Requirements
You must play at least one game with gaze tracking enabled (calibration completed), otherwise there is no gaze data to analyze.

---

## Notes / common issues

- If imports fail, make sure dependencies are installed (see requirements.txt or environment.yml) and if running from terminal if your in a directory '(...)\MemoryGame_App'.
- If gaze tracking doesn’t start, calibration may have failed or you chose “Skip Calibration”.
- Old gaze data may be moved into gaze_data/archived/ automatically at app start.
